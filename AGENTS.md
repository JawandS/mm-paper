# Code Style
- Always write high-quality code that is easy to read and maintain
- Add comments and docstrings explaining what the code is doing in a concise way
- Always use uv for python (e.g. `uv run main.py`, `uv add <package>`, etc.)
- Never directly use pip or python commands
- Look at PAPER.md on context for the research motivating this code
- Look at README.md for the overall project structure
