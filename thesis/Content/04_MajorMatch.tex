The fundamental goal was to help students who don't know what they want to major in to give them a starting place to explore.

The current version of (https://MajorMatch.me) represents the iteration of 6 version of several months. Feedback included speaking to users for qualitative feedback, considering user retention rates, and quantiative feedback (star ratings, and thumbs up / down). The latest version has been used more than 950 times. 

MajorMatch extends the TopProRec approach by replacing the open-ended topic browsing step with a more structured interest input. Rather than presenting students with a raw list of extracted keywords to sift through, MajorMatch guides them through a set of predefined dimensions that map to concrete aspects of academic programs. This reduces the cognitive burden of the interest elicitation step while preserving the core idea that a student's expressed preferences, not prior behavioral data, drive the recommendations.

The default dataset of MajorMatch includes popular majors accross the US. There are 106 majors spread accross 8 clusters

MajorMatch works with 3 games (reference /home/js/mm/mm-paper/thesis/Figures):
- Game 1: Fact or Fiction. Provides binary choice. Each question represents 1 cluster with 8 clusters. Used to filter out clusters the user doesn't like
- Game 2: This or That. Provides forced binary choice ranking (I prefer X over Y). Indicates which ideas the user is more interesting (e.g.)
- Stage 1 matching: game 1 + 2 is used to select the top 1-4 clusters for the user
- Game 3: Select 3. User ranks their top 3 keywords from a set of 8 keywrods
- Stage 2 matching: game 2 + 3 is used to select up to 3 top programs from each cluster the user matched with in stage 1 with a confidence score for each program
