As students begin the college search process in late high school, identifying potential majors remains a significant challenge that can feel overwhelming. This thesis presents MajorMatch, a gamified web platform designed to elicit student preferences through an engaging interface that minimizes cognitive load. A dataset of 106 academic majors was represented as embedding vectors and divided into eight clusters through a combination of k-means clustering and subjective analysis. The system employs three distinct game modalities: a binary forced-choice game for initial interest filtering, a comparative trade-off game for relative valuation assessment, and a keyword ranking game to specify candidate majors. User responses feed into a two-stage matching system that first identifies academic clusters of interest, then selects top majors within each cluster using GPT-4.1-mini via API. Pilot deployments demonstrate strong engagement, with over 90\% of participants who completed one game continuing through all three. Surveyed users reported strong alignment between recommendations and their actual interests. This work demonstrates how recommender systems leveraging large language models can recover latent preferences with minimal mental effort from users.
